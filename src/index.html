Performance

Running two models at once does not add speed. Tokens are generated one after another, so a second loaded model only competes for the same VRAM and cores and makes both slower. Real speed comes from keeping one model entirely on the GPU — or from a mixture-of-experts model like gpt-oss:20b, which holds 20B parameters but activates only ~3.6B per token.

Measured on this machine

Runs a short fixed prompt through each model and reports real tokens/sec plus how much of it fitted on the GPU. Takes a minute or two, and loads each model in turn.
